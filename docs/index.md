# d3dplot

`d3dplot` postprocesses and plots D-Flow FM and SMT simulation results from the
command line. It is the Python successor of the Matlab tool `D3D_plot`.

## Start here

- [User guide](./user-guide.md): a step-by-step walkthrough, from a simulation
  folder to figures.
- [Command reference](./cli.md): every command and option.
- [Configuration reference](./configuration.md): every setting in the YAML file.
- [Output store](./output-store.md): where results, figures, logs and reports
  are written.
- [Coming from Matlab](./from-matlab.md): map `D3D_plot` options to d3dplot.
- [Gallery](./gallery.md): example figures.

The rest of the reference pages are listed in the [README](https://github.com/V-Chavarrias/Delft3D_plot/blob/main/README.md#documentation).
