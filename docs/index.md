# Delft3D_plot

Python tools to postprocess and plot D-Flow FM and SMT results. The project is
being implemented in phases; this site documents the commands and analyses
available in the current package, including known workflow limitations.

## Start here

- [User guide](./user-guide.md): inspect simulations, create a project, and
  understand the current validate/plot workflow.
- [From Matlab `D3D_plot`](./from-matlab.md): migrate common options while
  preserving Matlab time-selector and `ba_mor` behavior.
- [Gallery](./gallery.md): synthetic examples of supported plot views.
- [Reference](./reference.md): configuration, CLI, output store, variables,
  model input, and simulation discovery.
